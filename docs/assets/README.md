# Kestrel brand assets

* `logo.svg`: app tile, the primary mark. Use for avatars and the README.
* `logo-mark.svg`: the bird alone, `currentColor`. Use on any solid background.
* `logo-wordmark.svg`: tile plus the word Kestrel, for light backgrounds.
* `favicon.svg`: simplified tile for 16px to 32px.

Colors: orange `#CF6A0A`, cream `#F6F1ED`, wordmark ink `#2B1D14`.

Minimum size: 16px for `favicon.svg`, 32px for `logo.svg`, 24px tall for the wordmark.
Clear space: keep at least 1/8 of the tile width free on every side.

Do: keep the tile corner radius at 22%, use only the two palette colors on the mark.
Do not: add gradients, shadows or outlines; stretch, rotate or recolor the bird; put text inside the tile.
